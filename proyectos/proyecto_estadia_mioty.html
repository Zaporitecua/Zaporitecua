Proyecto Mioty en Redes con IA (Estadía)

Con José Israel Sánchez Acosta

INTEGRACIÓN DE TECNOLOGÍAS DE EDGE COMPUTING CON PLATAFORMAS DE IOT Y BIG DATA PARA APLICACIONES EN INTELIGENCIA ARTIFICIAL

Santiago de Querétaro, Querétaro. Agosto 2024

El proyecto "Integración de Tecnologías de Edge Computing con Plataformas de IoT y Big Data para Aplicaciones en Inteligencia Artificial" aborda la necesidad de gestionar eficientemente grandes volúmenes de datos provenientes de granjas de sensores. Se busca optimizar el almacenamiento, procesamiento y seguridad mediante tecnologías avanzadas como Mioty y Edge Computing, con el objetivo de reducir la latencia y mejorar la toma de decisiones en tiempo real. La iniciativa se enmarca en el desarrollo de un Laboratorio de Inteligencia Artificial para la investigación y aplicación de estas tecnologías.


El proyecto se divide en varias fases estratégicas, desde la investigación hasta la implementación. Se integran sensores IoT con módulos Mioty para capturar datos en tiempo real y un gateway Mioty que los preprocesa antes de enviarlos al servidor central. Se emplea Edge Computing en el gateway para reducir la latencia y optimizar el uso de recursos. Se tomó en cuenta el software en Python desarrollado por el equipo de Desarrollo de Software para filtrar, procesar y analizar la información en tiempo real. La infraestructura de red y seguridad se refuerza con routers y firewalls de MikroTik y Cisco Meraki. Los datos procesados se almacenan y analizan en un servidor físico dentro del laboratorio de inteligencia artificial. Se comparan tecnologías como Mioty y LoRa para elegir la más adecuada según las necesidades del proyecto. Se evalúan costos, requisitos físicos y virtuales, asegurando la viabilidad del sistema a corto y largo plazo.
